Metric definitions / 指标口径

Sales / 销售额: quantity × USD unit price × (1 − discount), rounded HALF_UP per line. Merchandise only; excludes tax, shipping, fees and costs.

Refunds / 退款额: valid refunds linked to selected sales, assigned to original sales date. Net sales / 净销售额: sales less refunds, not profit.

Orders / 订单数: distinct channel + order ID. Category order counts are not additive. AOV / 平均订单金额: selected sales / selected orders; category filters only include selected merchandise.

Refund order rate / 退款订单率: orders with positive valid refunds / selected orders. Returning share / 老客订单占比: source-marked returning orders / selected orders, not retention.

Comparison: full calendar months compare to the preceding calendar month. Custom ranges compare to the immediately preceding equal-length period. Comparison requires complete baseline coverage. Zero baseline money/count = unavailable; ratios compare in percentage points when both denominators exist.
